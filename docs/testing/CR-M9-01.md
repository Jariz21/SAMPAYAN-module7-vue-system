# CHANGE REQUEST: CR-M9-01

- **CR ID**: CR-M9-01
- **Title**: Student Information System (SIS) - Status Tracking & Duplicate Prevention[cite: 1]
- **Maintenance Type**: Perfective Maintenance & Refactoring[cite: 1]
- **Priority**: High
- **Target Version**: v1.1.0

## Problem / Opportunity
The previous monolithic baseline lacks record status visibility and allows duplicate student entries without client-side blocking[cite: 1].

## Desired Outcome
Centralize system state, provide active/inactive record filtering, and prevent duplicate student number submissions[cite: 1].

## Acceptance Criteria
1. Displays an "Active" or "Inactive" status tag per record and supports real-time filtering (`All`, `Active`, `Inactive`)[cite: 1].
2. Submissions containing an existing `Student Number` are blocked and display a red error banner (`⚠️`)[cite: 1].
3. Primary form submit buttons are resized to standard action padding while preserving yellow Edit buttons[cite: 1].
4. All state changes persist across reloads via `localStorage`[cite: 1].
