# Change Request: CR-M9-01

| Field | Content |
| :--- | :--- |
| **CR ID** | CR-M9-01 |
| **Title** | Student Information System (SIS) |
| **Type** | Perfective Maintenance & Refactoring |
| **Problem** | The previous monolithic baseline lacks record status visibility and allows duplicate student entries without client-side blocking. |
| **Desired Outcome** | Centralize system state, provide active/inactive record filtering, and prevent duplicate student number submissions. |
| **Acceptance Criteria** | 1. Displays an "Active" or "Inactive" status tag per record and supports real-time filtering (`All`, `Active`, `Inactive`).<br>2. Submissions containing an existing `Student Number` are blocked and display a red error banner (`⚠️`).<br>3. Primary form submit buttons are resized to standard action padding while preserving yellow Edit buttons.<br>4. All state changes persist across reloads via `localStorage`. |
| **Priority** | High |
| **Affected Areas** | `App.vue`, `RecordForm.vue`, `RecordList.vue`, `localStorage`, tests, README |
