## 📝 System Description
This Vue.js application provides a dynamic management interface for handling records efficiently. It allows users to perform full CRUD (Create, Read, Update, Delete) operations, filter records in real-time, and preserve all data locally in the browser.

* **Selected Module 6 Entity:** [Insert your Entity name here, e.g., Inventory Records / Laundry Items]

---

## ✨ Features Implemented
- [x] **Add Record:** Form with validation to create new entries.
- [x] **View Records:** Clean list/table display of stored data.
- [x] **Edit Record:** Update existing details dynamically.
- [x] **Delete Record:** Remove entries with a confirmation check.
- [x] **Search / Filter:** Live search bar to filter records instantly.
- [x] **Data Persistence:** Automatic saving and loading using browser `localStorage`.
- [x] **Responsive UI:** Styled with Tailwind CSS for mobile and desktop screens.
